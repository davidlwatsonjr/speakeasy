International Morse Code Alphabet – Dots, Dashes and Audio

International Morse code represents letters and numbers as short and long signals. A dot (dit) lasts one time unit, a dash (dah) lasts three; the gaps within a letter, between letters and between words are one, three and seven units respectively.

How to practice

  1. Associate each letter with its sound pattern rather than counting each dot and dash.
  2. Start with a small group, such as E, T, I, M, A and N, then add more letters.
  3. Enable Morse audio in Study or Test to hear each prompt; use Replay to listen again.
  4. Practice common words, then use Type to encode a message or decode dots and dashes.

SpeakEasy synthesizes tones locally and includes letters, digits and several common punctuation marks. The standard timing pattern is used; no audio downloads or network connection are needed after installation.
